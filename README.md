# zcc0030's Scoop Bucket

Official [Scoop](https://scoop.sh/) bucket for [**XiZiTerm**](https://github.com/zcc0030/XiZiTerm) — Self-hosted Zero-Knowledge E2EE Cross-platform SSH Terminal & SFTP Manager.

## Quick Start

```powershell
# 1. Add bucket (one-time)
scoop bucket add zcc0030 https://github.com/zcc0030/scoop-bucket

# 2. Install XiZiTerm
scoop install xiziterm
```

## Upgrade & Uninstall

```powershell
# Upgrade to the latest release
scoop update
scoop update xiziterm

# Uninstall
scoop uninstall xiziterm
```
